# Neev Grover — Personal Website

Source code for **[neevgrover.com](https://neevgrover.com)** — my personal website

## Tech Stack

- **Astro** (fully static, zero client-side framework)
- **TypeScript**
- **Tailwind CSS v4**
- **astro-icon** (Iconify) for icons, self-hosted **Inter** font
- **Bun** for installs and scripts, **Biome** for lint/format
- Deployed on **Vercel**
